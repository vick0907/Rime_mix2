## 安裝方式

1. 從[官方網站](https://rime.im/download/)安裝含 Lua 支援的小狼毫。已驗證小狼毫 0.17.4、librime 1.13.1。
2. 在本專案點選 **Code > Download ZIP**，解壓縮下載的檔案。
3. 右鍵點小狼毫圖示，開啟「使用者資料夾」（`%APPDATA%\Rime`）；已有設定時請先備份。
4. 將本專案根目錄的 `.yaml`、`.lua`、`.txt` 檔案，以及 `lua`、`opencc` 兩個資料夾複製進去並覆蓋。不要複製到小狼毫的程式安裝目錄。
5. 右鍵點小狼毫圖示執行「重新部署」，完成後按 `F4` 選擇 **新注音**。

37 個標準注音符號一律使用候選選字，不再自動轉成注音。按注音鍵加空白後，中文仍優先，另提供標為「〔注音〕」的候選；按 `Down` 選注音，再按空白確認，就會保留在組字區。例如 `1`（ㄅ）、`t`（ㄔ）、`u`（ㄧ）都用相同方式。

連打 `cl32`（ㄏㄠˇㄉ）再按空白，可從候選選「好ㄉ」，再按空白保留整段組字。繼續輸入並選取下一組「好ㄉ」，即可組成「好ㄉ好ㄉ」，最後按 `Enter` 一次輸出。完整注音仍正常選中文字；退格可刪除注音，`Esc` 可取消混打組字。不需要額外快捷鍵或手動前綴。

混打片語最後確認輸出三次後，會記住同一輸入碼的選字偏好並提高順位，例如「讚ㄉ」。只選候選但取消、或刪除注音後提交，不會計入。偏好存在個人的 `new_bopomofo_preferences.userdb`，重啟後保留，不會上傳 GitHub；既有中文詞庫仍照常學習。舊版未記錄的混打次數不會回補。

本專案不包含小狼毫安裝程式、內建倉頡副本或個人詞庫；洋蔥方案、字典與 OpenCC 資料是設定的必要依賴，請一併複製。更新時不要刪除既有個人詞庫、同步資料或自訂外觀設定。

以[洋蔥 mix-in](https://github.com/oniondelta/Onion_Rime_Files)為基礎修改；英漢字典來源為 [ECDICT](https://github.com/skywind3000/ECDICT)。
